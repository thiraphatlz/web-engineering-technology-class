# Tutorial: สร้างเว็บ CRUD ด้วย Express และ Next.js

บทเรียนภาษาไทยในไฟล์เดียว (`index.html`) สำหรับเตรียมสอบเขียน backend + frontend ทำ CRUD และอัปโหลดรูป
ไม่มี build step ไม่มี dependency เปิดไฟล์ได้เลย

## ต้องอ่านอะไร

| ซ้อมก่อนสอบ | **ห้องสอบ** ทำข้อ 1-6 หนึ่งรอบ |

## ส่วน "ห้องสอบ" ทำอะไร

ตัวอย่างโจทย์ Book 1—N Review ใช้ Express ตัวเดียวเสิร์ฟทั้ง API และหน้าเว็บ (จึงไม่มีปัญหา CORS) เขียนเองแค่ 3 ไฟล์:

```
my-exam/
├─ prisma/schema.prisma   แปลงจาก ER
├─ src/app.js             API ทั้งหมดในไฟล์เดียว (CRUD + อัปโหลดรูป + รีวิว)
└─ public/index.html      หน้าเว็บ + JavaScript
```

ลำดับ: ติดตั้ง → ER เป็น schema → `npx prisma db push` → `app.js` → ทดสอบด้วย curl → หน้าเว็บ → (ถ้ามี) ใช้ HTML/CSS ของโจทย์ → (ถ้าหัวข้อไม่ใช่หนังสือ) เปลี่ยนชื่อ

คำสั่งใช้ได้ทั้ง PowerShell และ cmd

## ดูหน้าเว็บในเครื่อง

```bash
# เปิดไฟล์ตรง ๆ ก็ได้ หรือเปิดเป็นเว็บ:
npx serve tutorial
```

หน้าเว็บสลับส่วนด้วย `#hash` ใน URL เช่น `index.html#exam`, `index.html#quick`

## ถ้าจะแก้ไฟล์

ทุกอย่างอยู่ใน `index.html` ไฟล์เดียว (CSS, เนื้อหา, JavaScript)

- **ส่วนต่าง ๆ** คือ `<div class="part" id="part-...">` ครั้งละส่วนเดียวที่แสดง สารบัญด้านข้างสร้างจาก `data-toc` ของแต่ละ `<section>` และเลขหัวข้อมาจาก `data-n`
- **กล่องโค้ด** เขียนเป็น `<script type="text/plain" data-file="ชื่อไฟล์">...</script>` แล้ว JavaScript ของหน้าแปลงเป็นกล่องพร้อมปุ่มคัดลอก
  - ถ้าโค้ดข้างในมี `</script>` ให้เขียนเป็น `<\/script>`
  - ใส่ `data-nowrite` ถ้าไม่ต้องการให้เอาไปรวมในสคริปต์ PowerShell ที่สร้างไฟล์ของส่วน A (ส่วน A รวมเฉพาะบล็อกที่ชื่อขึ้นต้น `api/` หรือ `web/`)
- **รูปแบบขั้นตอน** ใช้ `<div class="qstep">` กับ `<div class="do">` (ทำ), `<div class="see">` (ต้องเห็น), `<div class="fail">` (ไม่ใช่?)
- **โค้ดในส่วนห้องสอบ** ทดสอบรันแล้วจริง (curl และเบราว์เซอร์) ถ้าแก้โค้ดในส่วนนี้ ให้รันทดสอบใหม่ก่อน deploy

## Deploy

โฟลเดอร์นี้เป็นเว็บ static ล้วน (ลิงก์กับ Vercel ไว้ใน `.vercel/` ซึ่งไม่ถูก commit) จากโฟลเดอร์ `tutorial`:

```bash
vercel --prod
```

ไฟล์ `.env*` และ `.vercel` ถูกละไว้ใน `.gitignore` แล้ว อย่า commit
